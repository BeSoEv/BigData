# Spark Optimization

Проект по выполнению домашнего задания «Оптимизация вычислений в Spark»

## Структура

- `notebooks/task_1_join_strategies.ipynb` — решение задания 1 (сравнение стратегий JOIN, анализ физических планов и производительности)
- `notebooks/task_2_data_skew.ipynb` — решение задания 2 (сравнение способов обработки перекоса данных)
- `notebooks/task_3_user_features.ipynb` — решение задания 3 (построение пользовательских признаков и проверка корректности)
- `data/task1/` — исходные данные для задания 1
- `data/task2/` — исходные данные для задания 2
- `data/task3/` — исходные данные для задания 3
- `results/` — результаты выполнения заданий
- `scripts/generate_event_log.py` — скрипт генерации событий для задания 1
- `docker-compose.yml` — конфигурация Docker Compose
- `Dockerfile` — сборка окружения Jupyter
- `Dockerfile.spark` — сборка окружения Spark с поддержкой S3A

## Запуск

1. Скачать архив и распаковать его
2. Перейти в корневую директорию проекта
3. Запустить контейнеры:

   ```bash
   docker compose up -d --build
   ```

4. Открыть Jupyter по адресу `http://localhost:8888`
5. Открыть ноутбуки в папке `notebooks/`
6. Выполнить ячейки последовательно в соответствии с заданиями
